How to prepare your SVG

1. Create the L, C and R groups

Set up a horizontal stretchable element in Illustrator. Name the three groups exactly L, C and R: left cap, repeating centre and right cap.

Keep these groups at the top level, without an extra group around them. Put all visible artwork inside them and use one artboard for the complete element.

Screenshot: artwork and Layers panelShow the complete element on its artboard, with the Layers panel expanded to show the three top-level groups named L, C and R.

2. Make C one repeatable tile

The centre should contain one complete repeat. Its left and right edges need to join when copies are placed side by side. Check this by temporarily duplicating C horizontally, then remove the extra copies before exporting.

The converter uses C’s artwork bounds to detect the tile width, then subtracts 1 unit for overlap between repeats. You can change the resulting width in Adjust settings.

Screenshot: checking the centre repeatShow one centre tile and three copies placed side by side, with the joins marked so designers can see how the edges meet.

3. Overlap the endcaps if needed

L and R keep their shape as the element gets wider. They can extend into C to cover the joins. Draw any overlap into the original artwork; the converter detects it from the group positions.

For example, if C starts at x = 80 and L reaches x = 90, the left cap overlaps the centre by 10 units. Do the same at the right join if required.

Screenshot: endcap overlapShow a close-up of both joins with L blue, C green and R red. Mark the nominal centre boundaries and highlight the artwork overlapping each boundary.

4. Export, convert and check

Outline text and strokes that define the tile edges, and expand rotated or skewed section transforms. Export an SVG from Illustrator with the artboard and group names preserved.

Upload the SVG, resize the preview and use Show section colours to check the joins. Download the converted SVG and import it into the design app. Preview width and diagnostic colours are not included in the download.
